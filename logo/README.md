# ZH. logo — vector pack

The brand mark from [zubair-hussain-portfolio.detroonshah.workers.dev](https://zubair-hussain-portfolio.detroonshah.workers.dev/),
redrawn as **outlined vectors** (no font needed to open or print them).

| Mark | Source on the portfolio |
| --- | --- |
| **ZH.** — "ZH" in Instrument Serif Italic `#f5f4f0`, dot in brand crimson `#c8141e` | header logo |
| **Z tile** — white bold "Z" on a `#ff0000` rounded square (rx 8/32) | `/icons/favicon.svg` |
| **ZH. \| Time Portal** — mark + product name in Hanken Grotesk SemiBold | this app's nav / sign-in |

## Files

| File | `svg/` (vector) | `pdf/` (vector) | `png/` (@2x raster) |

| Lockup, dark backgrounds | `time-portal-lockup-dark.svg` | `…-dark.pdf` | `…-dark@2x.png` |
| Lockup, light backgrounds | `time-portal-lockup-light.svg` | `…-light.pdf` | `…-light@2x.png` |
| Lockup on black | `time-portal-lockup-on-black.svg` | `…-on-black.pdf` | `…-on-black@2x.png` |
| App icon / favicon | `zh-app-icon.svg` | `zh-app-icon.pdf` | `zh-app-icon@2x.png` |

SVG and PDF open in Figma, Illustrator, Inkscape and Affinity as editable paths
(Illustrator can save the PDF as `.ai` or `.eps` if you need those).

The root files `logo.svg` (ZH. mark) and `logo-mark.svg` (Z tile) are the same vectors, and
`public/logo.svg` / `public/favicon.svg` are what the app serves.
